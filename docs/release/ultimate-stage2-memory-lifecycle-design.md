# ThreadPack 阶段 2 设计：可信记忆生命周期

日期：2026-11-27

## 数据状态

事实状态继续与来源分开保存。`origin` 表示记录来自用户还是 AI。用户记录但未确认的事实使用 `origin=user` 和 `needs-review`。AI 提取始终是 `origin=ai` 和 `proposed`。`confirmed` 只有显式用户操作可产生，仍须单独检查阶段 1 的签名认证状态。记忆类别包括独立的 `preference`，用于用户偏好，并与事实状态、来源和信任等级分开管理。

事实状态集合扩展为：

- `proposed`：AI 候选，尚未用户审阅。
- `needs-review`：用户或系统要求复核的记录，包括尚未确认的用户记录和冲突项。
- `confirmed`：用户明确确认。`confirmationTrust` 独立表达签名是否有效。
- `rejected`：用户拒绝的历史主张。
- `superseded`：被具有 `supersedes` 关系的新事实取代。
- `expired`：达到可选到期时间的历史主张。
- `revoked`：用户撤销先前接受的主张。

`rejected`、`superseded`、`expired`、`revoked` 都是终态。它们不能被状态更新 API 重新确认或编辑。用户要重新考虑历史内容时，创建新的 `needs-review` 事实并显式关联旧事实，保留旧记录和状态历史。

## 状态转换

| 当前状态 | 允许的操作 |
| --- | --- |
| proposed | 用户确认、标记复核、拒绝；被新事实取代时 superseded |
| needs-review | 用户确认、拒绝、到期；被新事实取代时 superseded |
| confirmed | 标记复核、拒绝、显式撤销、到期、被新事实取代 |
| rejected | 只读，可由独立新事实显式 reconsider |
| superseded | 只读，可由独立新事实显式 reconsider，不反向恢复 |
| expired | 只读，可由独立新事实显式 reconsider |
| revoked | 只读，可由独立新事实显式 reconsider |

确认对象、evidence 变化或事实版本变化继续触发原签名确认撤销。已确认事实的拒绝、显式撤销、到期及取代，在本地信任身份可用时写入签名事件，并在终态状态历史条目引用事件 ID、哈希和签名密钥 ID。到期或取代的原确认事件保留，并单独记录确认撤销事件。缺少本地信任密钥时保留状态和历史，但标记为未认证。

## 到期语义

用户可为事实设置可选 `expiresAt`。时间使用 epoch 毫秒保存。到期在浏览器项目记忆读取、状态审核、任务查询、共享更新箱读取或备份导出时惰性物化，写入 `expired` 状态、`expiredAt` 和 `statusHistory`。Context 和 MCP 对超过有效期但尚未物化的事实也即时按过期投影。终态事实不再进入当前上下文、MCP 任务集合或 AI 建议上下文，导出时保留在单独的历史台账。

若已签名确认的事实到期，确认签名仅作为历史事件保留，当前事实状态为 expired，输出显示终态并注明原确认已撤销。到期时间包含在确认事件细节中，更改到期设置会使其认证失效。旧版没有生命周期绑定字段的确认事件继续按阶段 1 格式验证。

## 拒绝去重与显式重新考虑

项目内新建候选会与所有终态事实比对规范化主张文本及 task state。相同主张不能仅凭新 ID 重新进入。自动提取无法重新激活终态主张。用户可通过明确的“重新考虑”操作创建新的 `needs-review` 事实，链接 `reconsiders` 到原记录，再进行常规审核。更正仍有效的事实则由用户显式选择“取代”记录，以 `supersedes`/`supersededBy` 成对关联并保留历史。

该规则用于精确规范化重复检测，不声称具备语义等价判断能力。语义相近但文本不同的主张仍通过现有冲突治理进入 `needs-review`。

## 历史与兼容

- 既有状态名称和 status history 保留。
- `user-recorded` 通过 `origin=user` 与 `status=needs-review` 表达，不把来源误作确认。
- 新字段为可选新增字段，旧备份无需数据库 schema 迁移。
- 导入备份里的确认或生命周期状态不会因数据自身携带状态值而获得本地签名认证。状态来源项目 ID 随事件关联元数据保留，生命周期信任状态导入时降为未认证。用户使用匹配恢复密钥重新信任后，事件可以按原项目身份和事件链复核。
- 状态历史上限为每个事实 10,000 个条目。超出上限时拒绝后续变化以防止静默丢失历史。
- 浏览器、Markdown、JSON Context Pack、MCP、MCP Tasks 和备份按同一事实状态投影处理终态过滤。

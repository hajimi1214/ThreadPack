# ThreadPack 系统架构

## 当前边界

ThreadPack 当前由离线优先的浏览器应用、本地 IndexedDB 项目数据、CLI 和 stdio MCP 服务构成。浏览器项目存储包含项目、导入会话、revision、记忆事实、信任事件、候选更新及任务记录。持久层 schema 与备份/恢复逻辑负责保留原始记录和升级历史。

## 项目记忆读取路径

本地存储记录通过 `src/projects/memory-projection.ts` 转换成无写入副作用的规范只读投影。投影统一计算事实状态、终态历史、到期状态、用户确认信任、生命周期事件信任、证据绑定和证据关系。筛选与增量变化使用相同投影模型。

浏览器项目记忆面板和 Markdown Context 通过 `src/projects/memory-context.ts` 生成器读取投影。JSON Context Pack 在导出时复核投影和项目状态 key。MCP Context 与 Tasks 读取同一个投影模块。通过浏览器的本地共享文件连接时，用户保存项目变更会更新共享备份，MCP 在每次请求重新读取该文件。没有连接共享文件时，静态备份需由用户重新导出。

## 写入路径

浏览器中的用户审阅操作经项目 store 写入本地持久层。MCP 候选更新使用独立 inbox 和既有审核流程，候选不会自动成为正式确认事实。项目记忆投影为只读。MCP 写入能力按本地服务实例配置分配，并要求限定到一个项目。服务配置的客户端 ID 是未经外部平台认证的审计标签。客户端目录、配置向导和更强的客户端身份管理留待后续阶段。

## 信任边界

导入会话、对话消息、工具输出、证据引用、客户端 baseline 和 Context 文本都是数据。记录来源匹配不能证明语义支持，用户确认也不能代替独立验证。签名仅在已建立的本地信任链下说明事件获该项目本地密钥授权。对外导出明确标识来源和待审状态，不能把历史记录转为当前指令。

可选 AI 记忆提取由用户显式启用、选择会话并提交后，才向用户配置的端点发送有界摘录。远程端点必须使用 HTTPS，本地回环端点可使用 HTTP。生产 CSP 允许 HTTPS `connect-src` 以支持该明确配置的功能；它不代表应用会自动发送项目数据。WorkBuddy 等宿主应用还可能提供 ThreadPack 以外的本地工具，ThreadPack 不能限制宿主工具的文件范围。

## 部署限制

本地浏览器存储依赖当前浏览器 profile。MCP stdio 服务只读取显式选择的备份文件，不访问浏览器数据库。只有浏览器已连接并维护该共享文件时，MCP 后续读取才反映已保存的新项目状态。静态备份不会自动更新，也不能跨电脑同步。Linux 和真实客户端组合需分别实测。

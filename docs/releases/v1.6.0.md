ThreadPack 1.6.0 adds direct ZIP imports and broader browser compatibility.

### Import and compatibility

- Import ChatGPT-style ZIP downloads directly; the Worker selects a supported JSON, JSONL, Markdown, or text export locally.
- ZIP safety limits allow at most 256 entries and 100 MiB of expanded content. Unsafe paths and unsupported files are rejected without returning archive entry names.
- File imports fall back to `arrayBuffer()` or `FileReader` when `File.stream()` is unavailable.
- Media-query detection supports older browser listener APIs and environments without `window.matchMedia`.
- The installable PWA adds desktop display fallbacks, categories, and shortcuts for the demo and import guide.

### Verification

- 128 unit tests cover ZIP selection, unsafe paths, array-buffer fallback, cleaned bundles, redaction boundaries, and stale revisions.
- 66 browser tests cover direct ZIP import, download workflows, five interface languages, mobile layouts, offline behavior, and existing workflows.
- Production web and CLI builds, package dry-run, browser checks, and production dependency audit pass.

Conversation processing remains local. Redaction can miss sensitive values; review exported content before sharing.

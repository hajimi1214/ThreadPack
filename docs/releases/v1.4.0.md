ThreadPack 1.4.0 adds searchable code extraction, local syntax highlighting, and ZIP download for cleaned code.

### Code tools

- Search fenced snippets across a conversation, filter by available language, and choose wrapped or horizontal code lines.
- Preview highlighting uses bundled MIT lowlight with selected BSD-3-Clause highlight.js grammars. Previews are limited to 2,000 characters; unknown languages and highlighter errors fall back to plain text.
- Copy or download one complete cleaned code block, or create a ZIP containing all matches across pages. The Worker creates ZIP files using MIT fflate and safe message/block numbers with allowlisted extensions.
- The demo and examples/code-snippets.md contain TypeScript and Python examples. Imported code is displayed as text; it is not executed.

### Discovery and offline use

- The import guide covers Codex, Claude Code, ChatGPT, Claude, Markdown, and text files in English and Chinese.
- Canonical, Open Graph, and Twitter metadata, an application listing, sitemap, and 1200 × 630 share image describe the supported workflows.
- Sharing copies only the public application address.
- Dependency license notices are embedded in the offline HTML, available in Help, cached by the PWA, and included in release and npm packages.

### Verification

- 123 unit tests cover fence parsing, HAST sanitization, exact text preservation, plain-text fallback, ZIP contents, safe names, and license metadata.
- 64 browser tests cover highlighting, code search and filters, full code copy/download, ZIP extraction, offline licenses, sharing, import guide, and existing workflows.
- Production HTML and CLI builds, TypeScript checks, npm packaging, Windows/Linux CI, and production dependency audit pass.
- The 1.4.0 single-file HTML is 582,090 bytes (174,848 gzip bytes with maximum compression); version 1.3.0 was 460,245 bytes (135,168 gzip bytes). This increase includes selected local language grammars and runtime license notices; no grammar is fetched from the network.
- The local highlighter registers 15 selected grammars. Snippets above 2,000 characters display as plain text; copying and downloads retain the full cleaned content.

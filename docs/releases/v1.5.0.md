ThreadPack 1.5.0 adds a portable context bundle for sharing and archival.

### Portable context bundle

- Download one ZIP containing the cleaned Markdown transcript, normalized JSONL, aggregate cleanup report, a manifest, and cleaned code files.
- Include `handoff.md` only when the current conversation has nonblank handoff notes; empty drafts do not create an empty file.
- Generate the bundle in the local Worker with safe names and cleaned content. Original-view text and custom redaction values are excluded.
- Keep the existing individual Markdown, JSONL, report, handoff, and code ZIP exports available for smaller workflows.

### Verification

- 125 unit tests cover bundle entries, cleaned content, safe file names, omission of empty handoff notes, and stale revision rejection.
- 65 browser tests cover the export dialog, download feedback, mobile layout, five interface languages, and ZIP contents.
- Production web and CLI builds, package dry-run, browser checks, and production dependency audit pass.
- The 1.5.0 single-file HTML is 587,000 bytes (176,105 gzip bytes with maximum compression).

Conversation processing remains local. Redaction can miss sensitive values; review exported content before sharing. Normalized exports do not reopen native agent sessions.

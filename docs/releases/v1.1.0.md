ThreadPack 1.1.0 adds five interface languages, custom redaction, a redesigned workbench, and more reliable archive handling.

### Interface

- Switch between English, Simplified Chinese, Japanese, French, and Spanish from the language menu. Browser language is detected on first use, and a manual preference is remembered.
- A blue and white visual design with centered typography, floating illustration cards, rounded panels, and a grid workspace. No remote fonts or assets are required.
- Show only changed messages and inspect the cleanup categories next to each message.
- Searches inside long messages now show the matching excerpt, including matches beyond the initial preview.

### Privacy and workflow

- Add exact custom values to hide in the browser, or use `--redact-file <file>` in the CLI. Custom rules apply independently of built-in credential detection and are excluded from report settings and diagnostics.
- Custom values in handoff notes are scanned using a separate alias namespace.
- Per-conversation notes, pins, and handoff settings survive switching within the same archive. They remain in memory and are removed when the workspace is cleared, replaced, or closed.
- Worker operations use explicit archive references, preventing a cancelled import from changing the conversation used for subsequent cleaning or export.

### Downloads

- **ThreadPack-1.1.0.html** — self-contained offline browser application.
- **threadpack-1.1.0.mjs** — standalone CLI, requiring Node.js 20.19 or later.
- **ThreadPack-1.1.0-source.zip** — source, tests, documentation, and synthetic sample data.
- **SHA256SUMS.txt** — SHA-256 checksums for the three artifacts.

Redaction remains heuristic; review exported content before sharing. Interface language selection does not translate conversation data or canonical export markers. Handoffs are deterministic excerpts rather than AI summaries, and normalized exports are not native agent session files.

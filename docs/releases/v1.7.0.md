ThreadPack 1.7.0 adds an optional Markdown reading view for conversation messages and handoff previews.

### Markdown reading

- Switch between plain text and Markdown presentation in the workbench and handoff builder.
- Render GFM tables, task lists, links, and fenced code. Fenced code reuses the bundled local highlighter.
- Raw HTML stays escaped, remote images become text labels, and unsafe link protocols are rejected by the Markdown renderer.
- Copy, transcript export, and portable bundles continue to use the full cleaned source text.
- `react-markdown` and `remark-gfm` are bundled for offline use with their MIT notices.

### Verification

- 130 unit tests cover GFM output, inert HTML, image replacement, safe links, and runtime license notices.
- 68 browser tests cover Markdown toggles in messages and handoff previews, source-preserving copy, five languages, responsive layouts, and offline workflows.
- Production web and CLI builds, npm packaging, and production dependency audit pass.
- The single-file HTML is 783,342 bytes (233,531 gzip bytes at maximum compression).

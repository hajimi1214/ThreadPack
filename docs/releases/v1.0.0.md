ThreadPack is an offline toolkit for processing AI conversation exports. This release includes a browser workbench and a standalone Node.js CLI, with a shared TypeScript core.

### Downloads

- **ThreadPack-1.0.0.html** — open directly in a modern desktop browser. No server, installation, or API key is required.
- **threadpack-1.0.0.mjs** — standalone CLI for Node.js 20.19 or later. Run `node threadpack-1.0.0.mjs --help`.
- **ThreadPack-1.0.0-source.zip** — source code, tests, bilingual documentation, and synthetic sample data.
- **SHA256SUMS.txt** — checksums for the release artifacts.

### Included

- Import Codex, Claude Code, ChatGPT, Claude, generic message JSON, Markdown, and text.
- Remove embedded image payloads, clip long tool output, collapse exact repeated output, and redact common credential patterns.
- Inspect the original and processed transcript, pin messages, and compose a handoff with notes and recent context.
- Export Markdown, normalized JSONL, aggregate reports, and handoff documents.
- English and Simplified Chinese interfaces; no uploads, analytics, account, or external model calls.

### Validation and boundaries

The release was checked with 44 core/CLI tests and 8 browser tests, including offline `file://` import/download and redaction regressions. Redaction is heuristic; review output before sharing. Handoffs contain user notes and deterministic excerpts, rather than an AI summary. Normalized exports do not replace native provider session files.

ThreadPack is an independent project and is not affiliated with OpenAI or Anthropic.

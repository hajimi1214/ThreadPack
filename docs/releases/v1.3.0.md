ThreadPack 1.3.0 adds code extraction, filtered exports, and faster review controls for local conversation files.

### Code extraction

- Collect closed Markdown code fences across the selected conversation, with 20 snippets per page.
- Preview, copy, and download TypeScript, Python, JavaScript, shell, SQL, and other supported code blocks. Long code remains complete in explicit copy/download operations.
- Snippets come from the cleaned conversation. File names use fixed message/block ordinals and a language extension allowlist. Imported code is displayed as text and is never executed.

### Review and interaction

- Export all matching messages across pages with combined search, role, change, and pin filters. Original-view searches still export cleaned text.
- Apply Balanced, Share safely, or Keep text cleanup recipes while retaining custom redaction rules.
- Inspect individual original/cleaned message comparisons and copy complete messages.
- Open quick actions with Ctrl+K or ⌘K. Copy/export controls report pending, success, or failure and ignore stale completions after a conversation or file changes.
- Layout follows both screen width and height, including compact phones, landscape windows, tablets, and ultrawide monitors. Rotation preserves the current conversation, search, and pins.

### Getting started and sharing

- A standalone English/Chinese import guide covers supported Codex, Claude Code, ChatGPT, Claude, JSONL, and text files.
- Sharing copies only the public tool address. Conversation text and page parameters are excluded.
- Search and link-preview metadata, structured application data, a sitemap, and a 1200 × 630 project card describe the application without fabricated usage or rating claims.

### Downloads

- **ThreadPack-1.3.0.html** — standalone offline browser application.
- **threadpack-1.3.0.mjs** — CLI for Node.js 20.19 or later.
- **ThreadPack-1.3.0-source.zip** — source, tests, documentation, and synthetic examples.

Conversation processing remains local. Redaction can miss sensitive values; review exported content before sharing. Normalized exports do not reopen native agent sessions.

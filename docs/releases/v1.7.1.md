ThreadPack 1.7.1 closes credential-redaction gaps in URL user information and makes overlapping custom rules easier to audit.

### Security fixes

- Redact bare URL user information when common-secret cleanup is enabled. This covers database, Redis, HTTP(S), IPv6, literal multi-`@`, and percent-encoded credentials while preserving the authority host and URL path.
- Keep optional email cleanup from matching URL authorities, multi-`@` credential strings, and numeric-only host labels as if they were email addresses.
- Report custom-rule occurrences separately from replacement intervals. Existing `customRedacted` continues to count replacements whose winning alias is a custom alias.
- Keep email cleanup opt-in.

### Verification

- 141 unit tests cover URL formats, overlap counters, and exports through CLI, Worker, handoff notes, code ZIPs, and context ZIPs.
- 69 browser tests pass, including the URL credential and report privacy workflow.
- TypeScript checks, production build, and production dependency audit pass.

Open ThreadPack

Choose the right file

Codex and Claude Code

Choose a local session log in .jsonl format. Keep the original log intact; import a copy when a session is still active.

ChatGPT

Use the JSON file from your data export, commonly conversations.json. If the download is a ZIP, extract it first. Choose a conversation after importing.

Claude

Use the conversation JSON from your data export. Exports containing chat_messages are supported; multi-conversation archives can be browsed separately.

Text, Markdown and generic JSON

Open .txt or .md, paste text, or use JSON/JSONL messages with role and content. Explicit role headings help split plain text.

Review before downloading

  1. Click Import file, drop a file, or choose Paste text. The limit is 100 MiB.
  2. Choose a cleanup recipe and review the packed and original views. Add exact custom redactions if required.
  3. Search, filter, and pin the messages you need. Open Code snippets to copy or download complete fenced code blocks from the cleaned conversation.
  4. Download a complete transcript or all filtered results. Add notes in Handoff builder to carry selected context into a new chat.

Conversation text, notes, and custom rules stay in tab memory. Download what you need before closing or reloading. Redaction can miss secrets; review exported content before sharing. Normalized exports do not reopen a native agent session.

Missing content or unsupported files

Extract ZIP archives before opening them. Provider formats can change; check import notes for skipped records. External image references cannot reconstruct an image, and a cleaned export cannot restore removed content.

If a file does not open, try a smaller JSONL or text excerpt. For a bug report, use a small synthetic example and include the source tool and version. Report a format issue.

导入指南

选择本地对话文件，或直接粘贴文本。所有处理在浏览器中完成，导出会生成新副本。

  1. Codex / Claude Code：打开 .jsonl 会话日志，保留原始文件。
  2. ChatGPT：从数据导出中找到 JSON 文件，常见名称为 conversations.json。下载内容若为 ZIP，请先解压。
  3. Claude：打开包含 chat_messages 的 JSON 导出。多会话文件可在导入后切换。
  4. 文本和 Markdown：导入 .txt、.md，或使用“粘贴文本”。通用 JSON/JSONL 支持 role 和 content 消息字段。

文件上限为 100 MiB。导入后选择清理预设，检查原文和清理结果。可搜索、筛选、固定消息，或打开“代码片段”复制和下载代码。需要交接时，补充笔记后导出交接包。

关闭或刷新前请下载需要的内容。脱敏可能漏检，分享前检查导出文件。标准化导出不能直接恢复原生代理会话。
